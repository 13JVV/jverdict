# 사실관계 조사 기록

기획서와 판정 사례에 쓰는 사실을 출처와 함께 기록한다. 확인 날짜: 2026-11-02.

|---|---|---|
| 제주시 시행 | 2016-12-01 시작, 2017-06까지 계도기간 | 서울신문 2016-11-22 |
| 서귀포시 시행 | 2016-12 한 달 홍보 후 2017-01-01 시작 | 서울신문 2016-11-22 |
| 과태료 | 2017-07-01부터 (요일 위반 10만 원, 무단투기 20만 원) | 서울신문 2016-11-22 |
| 도 전역 확대 | 2017-07 | 제이누리 2026-08-12 |
| 수거 주기 변경 | 음식물 주 4회 → 매일, 가연성 주 2회 → 매일, 페트·플라스틱·스티로폼 주 1회 → 주 2회 | 서울신문 2016-11-22 |
| 품목별 요일(현행) | 월·금 플라스틱, 화·토 종이·병·불연성, 수 캔·고철, 목 스티로폼·비닐, 일 스티로폼·플라스틱·비닐 | 제이누리 2026-08-12 |
| 배출 시간(현행) | 오후 3시 ~ 다음 날 오전 4시 | 제이누리 2026-08-12 |
| 시설 | 클린하우스 1,613곳, 재활용도움센터 201곳(2017년부터 상시 배출 가능) | 제이누리 2026-08-12 |
| 시범 성과(도 발표) | 재활용품 분리수거량 하루 평균 240.6t → 325.6t (+36%) | 서울신문 2017-06-30 |

> **판정 사례 B의 핵심:** 제주시와 서귀포시의 시행 시점이 한 달 다르고, 과태료 시점(2017-07)이 따로 있다. 이 시차를 자연실험으로 쓴다. 다만 2017-07 이후에는 도 전역이 처치 상태라 장기 대조군이 없다. 장기 효과는 ITS(단절 시계열)로만 볼 수 있다는 한계를 판정서에 적는다.

## 2. 24시간 상시배출 시범과 연구용역

| 항목 | 내용 | 출처 |
|---|---|---|
| 계획 | 10월부터 제주시·서귀포시 동 지역 각 1곳, 2~3개월 시범 | 비건뉴스(2026-09 초) |
| 진행 상황 | 서귀포시는 후보 지역 추천, 제주시는 8월 말까지 참여 희망 동 없음 | 비건뉴스(2026-09 초) |
| 연구용역 | 1억 원(제2회 추경), 9~10월 착수 계획 | 제이누리 2026-08-12 |
| 결정 시점 | 2027년 중 폐지 또는 보완 결정 | 제이누리 2026-08-12 |
| 정치적 배경 | 위성곤 지사 공약(요일별 배출제 폐지, 상시 분리배출 전환), 도민 반대 의견 존재 | 트위그뉴스 2026-09-23 |
| 우려 | 혼합배출로 재활용률 하락, 청소차·인력 증원 필요(제주시 청소차 79대, 수거 인력 356명) | 제이누리 2026-08-12 |

> **판정 사례 C의 방향:** 11월 초 기준 시범지역 확정 보도를 찾지 못했다. 그래서 사후 판정 대신 **사전 평가 설계**(어느 동을 시범지역으로 하면 평가가 가능한지, 대조군은 어디인지, 2~3개월로 결론이 나는지)를 핵심으로 둔다. 시범이 시작됐다면 중간 판정(대부분 '보류')을 함께 낸다.

## 3. 청소년 버스 무료

| 항목 | 내용 | 출처 |
|---|---|---|
| 시행일 | 2025-08-01 | 뉴스서울, 세계일보 2025-08 |
| 대상 | 만 13~18세 청소년(학교 밖 청소년 포함), 모든 노선버스 시간·노선 제한 없음 | 뉴스서울 |
| 어린이 | 기존 시내버스 무료에서 급행버스·공항 리무진까지 확대 | 뉴스서울 |
| 이용 조건 | 제주교통복지카드 발급(제주 주민등록 만 6~18세) | 뉴스서울 |
| 도 발표 실적 | 2025-08 ~ 2026-02 누적 483만 건, 대상 8만 6천여 명 중 5만 9,421명(68.6%) 카드 등록 | 트위그뉴스 2026-04-08 |

> **판정 사례 A의 핵심:** 버스 승객별 이용 현황(3-05)의 `user_type`에 '청소년'이 있다. 청소년(처치군) 대 일반(대조군) 이중차분이 가능하다. 시행일이 8월이라 **여름방학 효과**가 섞인다. 그래서 전년 같은 기간 대비 변화로 한 번 더 차분한다(삼중차분). 카드 승하차(3-06)의 `user_geton_fare`가 0원으로 바뀌는지로 정책 적용 여부도 확인한다.
