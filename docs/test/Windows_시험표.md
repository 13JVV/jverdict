# Windows PC 설치·실행 시험표 (Phase 5)

대상 묶음: `dist/JVerdict_win64_<날짜>.zip`. 같은 폴더의 `.sha256` 파일에 압축 파일 지문이 있습니다.
목적: 공모전 심사·센터 PC와 비슷한 Windows 환경에서 **인터넷 없이, 설치 없이** 정책 판정관이 돌아가는지 확인합니다.
소요 시간: 30분 안팎.

## 준비
- Windows 10 또는 11 64비트 PC 1대(가능하면 Python을 설치한 적이 없는 PC)
- 묶음 zip을 USB나 클라우드로 옮깁니다.
- (선택) 오프라인 조건을 시험하려면 3단계부터 **Wi-Fi·랜선을 끊고** 진행합니다.

## 시험 순서

| # | 할 일 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | zip 오른쪽 클릭 → 속성 → **차단 해제**에 체크 → 확인 | 문제 없이 바뀜 | ☐ |
| 2 | `C:\JVerdict`에 압축 풀기(Windows 기본 '압축 풀기'로 먼저 시험) | `JVerdict\실행.bat` 등 **한글 이름이 정상으로** 보임 | ☐ |
| 3 | (선택) 인터넷 끊기 | | ☐ |
| 4 | `점검.bat` 두 번 클릭 | 1~3분 뒤 **실패 0**(주의가 있으면 내용을 적어 주세요) | ☐ |
| 5 | `outputs\doctor\점검_*.txt` 파일 확인 | 보고서가 있고 경로가 `<설치 폴더>`로 가려져 있음 | ☐ |
| 6 | `실행.bat` 두 번 클릭 | 브라우저에 '어떤 정책의 효과가 궁금하신가요?' 화면 | ☐ |
| 7 | 예시 버튼 **(시연) 정답 있는 합성데이터** → **판정 시작** → 정책 카드 **승인** | 진행 표시 뒤 판정 '효과 있음(증가)', 추정 변화 **+19.6%** | ☐ |
| 8 | 판정서 `재현·내려받기` 탭 → **지금 재실행해서 확인** | 수치·판정·문장 모두 '같음' | ☐ |
| 9 | 같은 탭 → **1장 판정서 PDF 만들기** → **1장 판정서 PDF** 내려받기 | PDF 1쪽, 한글·그래프 정상 | ☐ |
| 10 | 왼쪽 메뉴 '지난 판정서' → `case-A-claude` 고르고 **열기** | 판정 보류 판정서, 그래프 표시 | ☐ |
| 11 | 왼쪽 메뉴 → **정확도 리포트(합성데이터)** | 표·검정력 곡선 표시 | ☐ |
| 12 | 처음으로 → 예시 버튼 **청소년 버스 무료화** → 판정 시작 → 승인 | 판정 '판정 보류'(측정 단절) | ☐ |
| 13 | `실행.bat`을 한 번 더 실행(첫 창은 켜 둔 채) | "8501 포트를 이미 쓰고 있어 8502로 엽니다" 안내 후 새 화면 | ☐ |
| 14 | 명령 창 `Ctrl+C`로 종료 | '일괄 작업을 끝내시겠습니까 (Y/N)?'가 나오면 Y → 창이 닫힘 | ☐ |
| 15 | (선택) 반디집·7-Zip으로 **다른 폴더**(`D:\시험\JVerdict` 등 한글 포함 경로)에 다시 풀고 `점검.bat` | 실패 0 | ☐ |
| 16 | (선택, 인터넷 연결) `.env`에 키를 넣고 Claude 모드로 사례 C 실행 | 판정 완료, 비용 약 $0.1 | ☐ |

## 알려진 주의
- 화면 시험(AppTest)을 할 때 명령 창에 Streamlit 경고 문구가 한 줄 나올 수 있습니다. 동작에는 문제가 없습니다.
- 코드 지문 '다름(정보)': 제출본의 Claude 기록은 이후 코드 수정 전에 만든 것입니다. 수치·판정·문장이 같으면 재현으로 봅니다.

3. Windows 버전: 설정 → 시스템 → 정보 → 'Windows 사양'의 에디션·버전
