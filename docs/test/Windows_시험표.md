- **대상 묶음**: `dist/JVerdict_win64_20261108.zip` (219MB)
- **목적**: 심사위원 PC처럼 Python이 없는 Windows에서 설치·관리자 권한 없이 압축을 풀고 바로 돌아가는지 확인합니다.

- 묶음 zip을 USB나 클라우드(iCloud·구글 드라이브 등)로 그 PC에 옮깁니다.

## 해도 되고 안 해도 되는 것

- **E1. Claude 모드**: `C:\JVerdict\JVerdict\.env.example`을 복사해 `.env`로 이름을 바꾸고 키를 넣습니다. 그다음 `실행.bat` → 왼쪽 메뉴 맨 아래 **실행 설정**에서 **Claude 판단**을 고르고, 질문 칸에 "청소년 버스 무료화로 청소년 버스 이용이 늘었나?"를 적어 판정합니다. 40~90초가 걸리고 약 $0.1이 듭니다. **시험이 끝나면 `.env` 파일을 꼭 지워 주세요.**
- **E2. 다른 압축 프로그램**: 반디집·7-Zip으로 한글이 들어간 다른 폴더(예: `D:\시험\정책판정관`)에 풀고 `점검.bat`을 실행합니다. 실패 0이면 통과입니다.
