# 사전 등록: 반합성(plasmode) 정확도 시험과 반론(Skeptic) 단계 성능 시험

- 등록일: 2026-11-09
- 상태: **잠금**. 실행 뒤 바꾸는 내용은 맨 아래 '변경 기록'에만 쓰고 사후 변경으로 표시한다.
- 왜 하는가: 외부 검토에서 두 가지 지적을 받았다. (1) 합성데이터 정확도(2,400회)는 잡음을 실데이터에 맞췄지만 실데이터의 이상 시점·구조 변화를 담지 못해 낙관적일 수 있다. (2) 판정을 낮추는 반론 단계의 성능은 사례 F 1건 말고는 잰 적이 없다.
- 결과가 지금 문서의 수치보다 나쁘게 나와도 그대로 보고한다. 결과를 본 뒤 판정 규칙·설계·날짜·효과 크기를 바꾸지 않는다.

## 1. 등록 시점에 이미 본 것(공개)

- 사례 A의 시점 위약검정(C2a)은 같은 버스 실데이터에서 가짜 시행일로 '효과'를 계산한 것이다. 그 분포(순위 p)는 사례 A 판정서에서 이미 봤다. 사례 B도 같은 카드 계열의 시점 위약을 봤다.
- 실행 코드가 오류 없이 도는지 보려고 계열마다 1건씩, 상황마다 1건씩 돌렸다. 소요 시간과 추정치가 계산되는지만 확인했고 판정 결과는 보지 않았다.
- 합성데이터 시험의 결과(오탐 2.4%, 검정력 곡선 등)는 이미 공개했다.

## 2. 반합성 정확도 시험 (`jverdict.synth.accuracy_plasmode`)

생성기를 쓰지 않는다. 실데이터의 정책이 없던 날짜를 가짜 시행일로 두고, 그날부터 대상 계열에 정해진 크기의 효과를 곱해 넣은 뒤(효과 0이면 그대로) 실제 판정과 같은 엔진·같은 설계로 판정한다.

| 계열 | 자료 | 대상 대 대조 | 공간 위약 | 계절 차분 | 쓰는 기간 | 가짜 시행일 |
|---|---|---|---|---|---|---|
| 버스(일) | 이용자 유형별 버스정류소 이용 인원 | 청소년 대 일반 | 경로, 장애 일반 | 3년 | ~2025-07-31(사례 A 정책 전) | 2022-01-03 ~ 2025-01-27, 2주 간격 월요일(81개) |
| 카드(월) | 업종별 성별 카드 이용 정보 | 도민 × 지원금 사용 가능 업종 대 사용 불가 업종(사례 B 계열 정의) | 법인 사용 가능 대 불가 | 1년 | ~2025-06 | 2019-07 ~ 2024-12 매월 1일 중, 3개월 전 ~ 6개월 뒤가 실제 지원금 기간(2020-05~08, 2021-09~12)과 겹치지 않는 날(42개) |

- 사전·사후 기간은 엔진 기본값(일 728일/182일, 월 24개월/6개월). 기준 효과 10%, 기대 방향 '증가'. 판정 규칙 v2(공식)와 v3(개정안)을 함께 기록한다.
- 심는 효과(로그): 0, 0.10, 0.20, 0.35(0%, +10.5%, +22.1%, +41.9%). 가짜 시행일부터 끝까지 일정한 크기.
- 보고하는 값(계열 × 효과 크기마다): '효과 있음(증가)' 비율, '효과 있음'·'조건부'(증가) 비율, '효과 없음' 비율, 판정 보류 비율, 방향 반대 비율, 판정 구간의 정답 포함률, 평균 MDE, 측정 단절 경고(C0 실패) 비율, 판정 분포 전체.
- 효과 0에서는 '효과 있음' 비율(오탐)과 '효과 있음'·'조건부' 방향 주장 비율을 따로 보고한다.
- 합성데이터 시험과 같은 효과 크기(+10.5%, +22.1%)에서 버스 계열 결과를 나란히 보고한다.
- 가짜 시행일끼리 분석 창이 겹쳐 독립 표본이 아니라는 점, '효과 0'이 '알려진 정책이 없던 날'이라는 뜻이라는 점을 결과와 함께 적는다.

## 3. 반론(Skeptic) 단계 성능 시험 (`jverdict.synth.accuracy_skeptic`)

합성 버스 데이터(시연 사례 C·F와 같은 생성기)에 같은 시기 청소년 행사를 심고, 오프라인 반론 단계와 같은 함수로 '사건 달력에 있는 사건 기간을 빼고 다시 추정 → 반론 성립 여부 → 판정 하향'을 거친다. Claude 반론 단계는 비용 때문에 넣지 않는다.

- 시드마다: 정책일 2023-03-01 ~ 2025-03-01 무작위, 행사 시작 = 정책일 + 7~28일, 길이 42~84일, 행사 크기 로그 0.25~0.45, 실제 효과 로그 0.15~0.30.
- 상황 5개 × 200회:

| 상황 | 내용 | 바라는 결과 |
|---|---|---|
| K1 | 정책 효과 0 + 같은 시기 청소년 행사, 달력에 있음 | '효과 있음'이 남지 않음 |
| K2 | 실제 효과 + 달력에만 있고 이용에 영향 없는 행사 | 판정을 낮추지 않음 |
| K3 | 실제 효과 + 같은 시기 청소년 행사, 달력에 있음 | 증가 방향 유지('효과 있음' 또는 '조건부') |
| K4 | 정책 효과 0 + 같은 시기 청소년 행사, 달력에 없음 | 반론 단계가 알 수 없는 한계를 확인(결과 그대로 보고) |
| K5 | 실제 효과, 행사 없음 | 기준선 |

- 보고하는 값: 판정 규칙만의 결과와 반론 단계 뒤의 결과(상황별 판정 분포 전체), K1의 '효과 있음' 비율, K2의 잘못된 하향 비율, K3의 방향 유지 비율, K4의 '효과 있음' 비율.
- 같은 데이터를 11-09 이전 반론 규칙(크기가 유지돼도 유의성이 사라지면 '성립')으로도 판정해 나란히 보고한다.

## 4. 결과를 문서에 쓰는 방법

- 결과 설명자료 5장(검증과 한계)과 화면의 정확도 리포트에 두 시험의 핵심 수치를 합성 시험 수치와 나란히 싣는다.
- 반합성 결과가 합성 결과보다 나쁘면 0장 요약 표의 정확도 줄에도 반합성 수치를 함께 쓴다.
- 결과를 보고 판정 규칙을 고치고 싶어지면, 고친 규칙은 v3처럼 '개정안'으로 따로 보고하고 이 시험의 공식 결과는 v2 그대로 둔다.
