# 사례 E 보조 확인: 제주도민 카드 소비 중 밤·저녁 비중

자료: 「시간대별 카드 이용 금액 현황」(시간대별카드이용금액현황.csv), 이용자 구분 제주도민. **사전 등록 밖의 보조 확인이며 판정에 쓰지 않는다.**

| 기간 | 밤 비중 | 저녁+밤 비중 |
|---|---|---|
| 2019 같은 달(5~9월, 코로나 전) | 11.5% | 42.4% |
| 2021-08 (거리두기 4단계 무렵) | 4.5% | 32.9% |
| 2022-01~03 (해제 직전, 단계적 완화) | 4.4% | 32.0% |
| 2022-05~09 (전면 해제 뒤) | 9.6% | 37.8% |
| 2023-05~09 (1년 뒤) | 9.1% | 37.7% |

- 시간대 구분의 정확한 시각은 허브 파일에 적혀 있지 않다. 월 합계 금액 기준 비중이다.
- 업종 파일과 다른 파일에서 같은 방향(영업시간 제한 해제 뒤 늦은 시간 소비 회복)이 보이는지만 확인한다.
