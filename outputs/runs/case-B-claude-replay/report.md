# 판정서: 1차 긴급재난지원금

## 🔴 판정 보류

**1차 긴급재난지원금이 사용 가능 업종의 제주도민 카드 소비를 늘렸는지는 현재 자료로 판단할 수 없어 '판정 보류'합니다.**

사후 4개월 평균은 -4.9%였으나 판정 구간이 -17.0%~+9.0%로 넓어 늘었다고도 줄었다고도 말하기 어렵습니다. 현재 자료로 구분 가능한 최소 효과는 ±16.0%로, 기준 효과 10%를 가려내기에는 검정력이 부족합니다. 시점 위약검정에서 가짜 시행일 40개 중 순위 p=0.317로 실패해, 계절·같은 시기 충격으로 나온 변화일 가능성을 배제하지 못했습니다. 따라서 이 결과를 정책 효과의 증거로 쓰기보다 추가 자료 확보 후 다시 판정하는 것이 적절합니다.

## 정책 카드

- 질문: 1차 긴급재난지원금(2020-05)이 사용 가능 업종의 제주도민 카드 소비를 늘렸는가?
- 시행일: 2020-05-01 · 대상: 제주도민(지원금 수령), 사용 가능 업종
- 결과지표: 업종별 월 카드 이용 금액
- 데이터: 업종별 성별 카드 이용 정보

## 근거

- 추정 효과 -4.9% (판정 구간 -17.0% ~ +9.0%, p=0.389), 분석 기간 2020-02 ~ 2020-08, 사전 3개월 · 사후 4개월.
- 검정력 부족: 구분 가능한 최소 효과 ±16.0%(기준 효과 10%). 표준오차가 지금의 1/1.6 이하여야 기준 효과를 구분할 수 있음.
- 시점 위약검정(C2a) 실패: 가짜 시행일 40개 중 순위 p=0.317. '해마다 이맘때 생기는 변화' 반론이 성립함.
- 같은 시기 업종별 충격(황금연휴 관광 반등, 유가 급락, 여름방학 등) 반론은 규칙 검증에서 성립함.
- 데이터 품질(C0) 통과(단절 없음), 공간 위약검정(C2b) 통과(실제 -4.9% vs 가짜 처치 +5.6%), 이중 계산(C4) 통과(pandas·SQL 모두 -0.049901242).
- 민감도(C3)는 3개 중 0개가 같은 방향·유의였고, 같은 방향은 3개였음(참고 수준).

## 검증 결과

| 항목 | 결과 | 내용 |
|---|---|---|
| C0 데이터 품질 | 통과 | 단절 없음 |
| C1 사전추세 | 해당 없음 | 사전 기간이 짧아 검정 불가 |
| C2a 시점 위약검정 | 실패 | 가짜 시행일 40개 중 순위 p=0.317 |
| C2b 공간 위약검정 | 통과 | 실제 -4.9% vs 가짜 처치 법인_가능 +5.6% |
| C3 민감도 | 참고 | 3개 중 0개 같은 방향·유의 (같은 방향 3개) |
| C4 이중 계산 | 통과 | 사후 평균 − 사전 평균(계절 차분 격차): pandas -0.049901242 / SQL -0.049901242 |

## 검정력

- 현재 구분 가능한 최소 효과는 ±16.0%입니다(기준 효과 10%). 기준 효과를 구분하려면 표준오차가 지금의 1/1.6 이하여야 합니다. 정책이 계속되는 경우 사후 기간 약 10개월(현재 4개월), 끝난 정책이면 더 세밀한 자료(일 단위·전체 카드사 등)가 필요합니다.

## 한계

- 사전 기간이 3개월로 짧아 정책 전부터의 기존 추세(C1)는 검정하지 못했음(미검증).
- 코로나19 확산기(2020-02~03)가 사전 기준선을 왜곡했을 가능성은 검증하지 못했음(미검증).
- 사용한 자료는 '업종별 성별 카드 이용 정보'로, 전체 소비를 대표하는지는 확인 필요.
- 사후 4개월은 효과를 가려내기에 짧음.

## 이 분석이 말할 수 없는 것

- 지급금이 카드 소비를 늘렸다고도, 늘리지 않았다고도 말할 수 없음.
- -4.9%가 정책 때문에 생긴 감소라고 원인을 단정할 수 없음.
- 정책의 전체 경제효과나 지역경제 파급효과는 이 분석으로 말할 수 없음.

## 판정에 필요한 데이터

- 사후 약 10개월의 관측 자료(정책이 계속되는 경우).
- 더 세밀한 단위의 자료(일 단위, 전체 카드사 등, 정책이 끝난 경우).
- 코로나19 확산기 이전의 더 긴 사전 기간 자료(기존 추세 검정용).
- 같은 시기 업종별 충격을 가려낼 수 있는 비교 업종·관광 관련 자료(시행일·대상 업종 세부는 확인 필요).
