# 사전 등록: 중국 단체관광 재개

- 이 문서는 효과 값을 보기 전에 만들어졌다. Design 단계에 전달된 자료는 데이터 계열 목록, 대조 후보, 커버리지 점검, 측정 단절 진단의 판정 이름·상한뿐이다(효과 크기가 담긴 Scout 메모는 넘기지 않음). 대조 선택 툴은 정책 전 기간만 본다.

## 1. 질문
- 중국 단체관광 재개(2023-08-10) 이후 제주의 중국인 카드 소비가 다른 외국인 대비 늘었는가?
- 정책 시행일: 2023-08-01
- 처치 대상: 중국인 방문객
- 결과지표: 업종별 월 카드 이용 금액(2019 같은 달 대비)
- 기대 방향: increase · 기준 효과: 20%

## 2. 데이터와 설계
- 데이터셋: 업종별 성별 카드 이용 정보 (`card_sector`)
- 방법: 단위 패널 이중차분
- 집단: 중국, 일본, 동남아, 기타외국 (처치: 중국)
- 분석 월: 2023-03-01, 2023-04-01, 2023-07-01, 2023-08-01, 2023-09-01, 2023-10-01, 2023-11-01, 2023-12-01, 2024-01-01
- 결과 변수: log(금액 / 2019년 같은 달 금액), 업종×월 고정효과 사용
- 이벤트스터디 기준 월: 2023-07-01
- 민감도: S1 사후 2023-09부터(8월 제외), S2 2019 연간 금액 가중, S3 면세점 제외

## 3. 데이터 점검 결과(Data Scout)
- 측정 단절 진단: 패널 설계: 시점별 결측 점검만 수행
- 커버리지: [집단 결측] 2023-05 ~ 2023-06 2개월 동안 기타외국, 동남아, 일본, 중국의 행이 없음 (같은 기간 내국인, 법인, 제주도민은 있음) (결측·부분 집계일은 분석에서 자동 제외)

## 4. 설계 선택과 이유
- 사전 등록 문서 사용(수정 1): docs/prereg/case_china_group_tour_2023.md (잠금 해시 확인)

## 5. 판정
- 판정 규칙 v2(`jverdict.causal.verdict`)를 그대로 적용한다. 결과를 본 뒤 설계를 바꾸면 변경 기록에 남기고 원안 판정을 함께 보고한다.
