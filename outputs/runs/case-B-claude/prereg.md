# 사전 등록: 1차 긴급재난지원금

- 이 문서는 효과 값을 보기 전에 만들어졌다. Design 단계에 전달된 자료는 데이터 계열 목록, 대조 후보, 커버리지 점검, 측정 단절 진단의 판정 이름·상한뿐이다(효과 크기가 담긴 Scout 메모는 넘기지 않음). 대조 선택 툴은 정책 전 기간만 본다.

## 1. 질문
- 1차 긴급재난지원금(2020-05)이 사용 가능 업종의 제주도민 카드 소비를 늘렸는가?
- 정책 시행일: 2020-05-01
- 처치 대상: 제주도민(지원금 수령), 사용 가능 업종(card_sector의 tier:가능 업종 묶음의 제주도민 이용 금액)
- 결과지표: 업종별 월 카드 이용 금액(원)
- 기대 방향: increase · 기준 효과: 10%

## 2. 데이터와 설계
- 데이터셋: 업종별 성별 카드 이용 정보 (`card_sector`)
- 방법: 단절 시계열(대상/대조 격차, 계절 차분)
- 계열 정의: 도민_가능 = {"groups": ["제주도민"], "units": "tier:가능"}; 도민_불가 = {"groups": ["제주도민"], "units": "tier:불가"}; 도민_대형종합 = {"groups": ["제주도민"], "units": ["기타 대형 종합 소매업"]}; 도민_불가면세 = {"groups": ["제주도민"], "units": ["기타 대형 종합 소매업", "일반유흥 주점업", "면세점"]}; 법인_가능 = {"groups": ["법인"], "units": "tier:가능"}; 법인_불가 = {"groups": ["법인"], "units": "tier:불가"}
- 대상: 도민_가능 / 대조: 도민_불가
- 사전 3 · 사후 4 · 계절 차분 1년
- 공간 위약: 법인_가능 vs 법인_불가
- 대체 대조(민감도): 대형종합만, 대형종합+유흥+면세
- 시점 위약 제외 기간: 2021-09-01~2021-12-01(상생 국민지원금); 2022-09-01~2022-12-01(상생 국민지원금의 1년 뒤 메아리)

## 3. 데이터 점검 결과(Data Scout)
- 측정 단절 진단: 확인 필요
- 커버리지: [집단 결측] 2023-05 ~ 2023-06 2개월 동안 기타외국, 동남아, 일본, 중국의 행이 없음 (같은 기간 내국인, 법인, 제주도민은 있음) (결측·부분 집계일은 분석에서 자동 제외)

## 4. 설계 선택과 이유
- 사전 등록 문서 사용: docs/prereg/case_relief2020_engine.md (잠금 해시 확인)
