# 판정서: 1차 긴급재난지원금

## 🟣 판정 보류

**1차 긴급재난지원금이 사용 가능 업종의 제주도민 카드 소비를 늘렸는지는 현재 자료로 판단을 보류합니다.**

사후 4개월 평균 추정 효과는 -4.9%이지만 판정 구간이 -17.0%에서 +9.0%로 넓어 늘었다고도 줄었다고도 말할 수 없습니다. 현재 자료로 구분 가능한 최소 효과는 ±16.0%여서 기준 효과 10%를 가려내기 어렵습니다. 정책 전 기간이 3개월뿐이라 사후 기간을 늘려도 이 문제는 풀리지 않습니다. 따라서 더 긴 정책 전 기간이나 더 세밀한 자료가 확보될 때까지 판정을 보류합니다.

## 정책 카드

- 질문: 1차 긴급재난지원금(2020-05)이 사용 가능 업종의 제주도민 카드 소비를 늘렸는가?
- 시행일: 2020-05-01 · 대상: 제주도민(지원금 수령), 사용 가능 업종 (card_sector의 tier:가능 업종 묶음, 이용자 구분: 제주도민)
- 결과지표: 업종별 월 카드 이용 금액(원)
- 데이터: 업종별 성별 카드 이용 정보

## 근거

- 추정 효과는 -4.9%이며 판정 구간은 -17.0% ~ +9.0%, p=0.389입니다(분석 기간 2020-02 ~ 2020-08, 사전 3개월·사후 4개월).
- 검정력 부족: 현재 구분 가능한 최소 효과는 ±16.0%로 기준 효과 10%보다 큽니다.
- 데이터 품질 검증(C0)은 통과했고 측정 방식 변경으로 숫자만 달라졌다는 반론은 기각되었습니다.
- 공간 위약검정(C2b)은 통과했습니다. 실제 -4.9%, 가짜 처치 법인_가능은 +5.6%였습니다.
- 이중 계산 검증(C4)은 통과했습니다. pandas와 SQL 결과가 모두 -0.049901242로 일치했습니다.
- 민감도(C3)는 3개 중 0개가 같은 방향·유의였고(같은 방향은 3개), 시점 위약검정(C2a)은 순위 p=0.317로 참고용입니다.

## 검정력

- 현재 구분 가능한 최소 효과는 ±16.0%입니다(기준 효과 10%). 정책 전 기간이 짧아(사전 3개월) 사후 기간을 아무리 늘려도 기준 효과를 구분할 수 없습니다. 더 긴 정책 전 기간이나 더 세밀한 자료(일 단위·전체 카드사 등)가 필요합니다.

## 한계

- 사전 기간이 3개월로 짧아 사전추세(C1)를 검정할 수 없고, 기존 추세 반론은 미검증입니다.
- 사전 기간이 코로나19 첫 확산기와 겹쳐 기준선이 왜곡되었을 가능성이 있으나 검증되지 않았습니다(의심).
- 계절 요인과 분석 기간·대조 선택에 따른 우연 가능성도 미검증으로 남아 있습니다.
- 자료가 업종별 성별 카드 이용 정보이며, 비씨카드 실적이 전체 소비를 대표하는지는 확인 필요입니다.
- 대조 집단을 바꾼 결과(-6.8%)와 사후 2개월 기준(-2.9%)은 해당 없음으로 처리되어 결론을 뒷받침하지 못합니다.

## 이 분석이 말할 수 없는 것

- 지원금이 소비를 늘렸다 또는 늘리지 않았다고 단정할 수 없습니다.
- -4.9%라는 숫자를 지원금이 소비를 줄인 증거로 읽을 수 없습니다.
- 현금·지역화폐·다른 카드사 등 카드 외 소비에 미친 효과는 이 분석으로 말할 수 없습니다.

## 판정에 필요한 데이터

- 더 긴 정책 전 기간의 자료(사후 기간만 늘려서는 해결 불가)
- 더 세밀한 단위의 자료(일 단위, 전체 카드사 등)
