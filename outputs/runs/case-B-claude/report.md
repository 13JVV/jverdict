# 판정서: 1차 긴급재난지원금

## 🟣 판정 보류

**1차 긴급재난지원금이 사용 가능 업종의 제주도민 카드 소비를 늘렸는지는 현재 자료로 판단할 수 없어 판정을 보류합니다.**

사후 4개월 평균 추정치는 -4.9%이고 판정 구간은 -17.0% ~ +9.0%로 넓어, 늘었다는 결론도 줄었다는 결론도 내리기 어렵습니다. 정책 전 기간이 3개월로 짧아 현재 구분 가능한 최소 효과가 ±16.0%이며, 기준 효과 10%를 가려내지 못합니다. 사후 기간을 늘려도 이 문제는 해결되지 않아, 더 긴 정책 전 기간이나 더 세밀한 자료가 필요합니다. 따라서 이번 결과는 효과가 없다는 증거가 아니라 판단 근거가 부족하다는 뜻으로 읽어야 합니다.

## 정책 카드

- 질문: 1차 긴급재난지원금(2020-05)이 사용 가능 업종의 제주도민 카드 소비를 늘렸는가?
- 시행일: 2020-05-01 · 대상: 제주도민(지원금 수령), 사용 가능 업종(card_sector의 tier:가능 업종 묶음의 제주도민 이용 금액)
- 결과지표: 업종별 월 카드 이용 금액(원)
- 데이터: 업종별 성별 카드 이용 정보

## 근거

- 추정 효과는 -4.9%(판정 구간 -17.0% ~ +9.0%, p=0.389)이며, 분석 기간은 2020-02 ~ 2020-08(사전 3개월, 사후 4개월)입니다.
- 검정력 부족: 현재 구분 가능한 최소 효과는 ±16.0%로 기준 효과 10%보다 큽니다.
- C0 데이터 품질은 통과(단절 없음)했고, C4 이중 계산도 pandas와 SQL 값이 -0.049901242로 일치했습니다.
- C2a 시점 위약검정은 실패했습니다. 가짜 시행일 40개 중 순위 p=0.317이라, 계절·시기 요인 반론이 성립합니다.
- C2b 공간 위약검정은 통과했습니다. 실제 -4.9%, 가짜 처치(법인_가능) +5.6%입니다.
- C3 민감도는 참고 수준입니다. 3개 모두 같은 방향이지만 유의한 것은 0개입니다.

| C2a 시점 위약검정 | 실패 | 가짜 시행일 40개 중 순위 p=0.317 |

## 검정력

- 현재 구분 가능한 최소 효과는 ±16.0%입니다(기준 효과 10%). 정책 전 기간이 짧아(사전 3개월) 사후 기간을 아무리 늘려도 기준 효과를 구분할 수 없습니다. 더 긴 정책 전 기간이나 더 세밀한 자료(일 단위·전체 카드사 등)가 필요합니다.

## 한계

- C1 사전추세는 사전 기간이 짧아 검정할 수 없어, 정책 전부터 변하던 추세인지 확인하지 못했습니다(미검증).
- 사전 3개월이 코로나19 초기 급락기(2~3월)와 겹쳐 기준선이 왜곡됐을 가능성이 있으며 이는 검증되지 않았습니다.
- 대조군(도민_불가)이 같은 시기 황금연휴 관광 반등, 유가 급락, 코로나19 충격을 다르게 받아 효과가 상쇄되었을 가능성이 규칙 검증에서 성립했습니다.
- 지급 직후 단기 효과가 4개월 창에서 희석되었다는 반론은 사후 2개월 기준 -2.9%로 해당 없음이었습니다.
- 자료는 업종별 성별 카드 이용 정보 한 종류이며, 일부 카드사 중심 자료일 가능성은 확인 필요합니다.

## 이 분석이 말할 수 없는 것

- 지원금이 카드 소비를 늘렸다거나 줄였다고 말할 수 없습니다.
- 지원금이 효과가 없었다고 말할 수 없습니다. 현재 자료로는 ±16.0%보다 작은 효과를 구분하지 못합니다.
- -4.9%라는 수치를 지원금 때문이라고 원인으로 단정할 수 없습니다.

## 판정에 필요한 데이터

- 더 긴 정책 전 기간의 자료(사후 기간만 늘려서는 해결 불가)
- 더 세밀한 단위의 자료(일 단위, 전체 카드사 등)
- 코로나19 초기 급락기 이전 기간을 포함한 기준선 자료
