# 사전 등록: 사회적 거리두기 전면 해제

- 이 문서는 효과 값을 보기 전에 만들어졌다. Design 단계에 전달된 자료는 데이터 계열 목록, 대조 후보, 커버리지 점검, 측정 단절 진단의 판정 이름·상한뿐이다(효과 크기가 담긴 Scout 메모는 넘기지 않음). 대조 선택 툴은 정책 전 기간만 본다.

## 1. 질문
- 사회적 거리두기 전면 해제(2022-04-18)로 제주도민의 주점 소비가 늘었는가?
- 정책 시행일: 2022-04-01
- 처치 대상: 영업시간·모임 제한을 받던 주점(일반유흥 주점업, 기타 주점업). 시행 4-18이라 4월은 절반만 처치(월 단위)
- 결과지표: 업종별 월 카드 이용 금액(제주도민)
- 기대 방향: increase · 기준 효과: 10%

## 2. 데이터와 설계
- 데이터셋: 업종별 성별 카드 이용 정보 (`card_sector`)
- 방법: 단절 시계열(대상/대조 격차, 계절 차분)
- 계열 정의: 도민_주점 = {"groups": ["제주도민"], "units": ["일반유흥 주점업", "기타 주점업"]}; 도민_식료품 = {"groups": ["제주도민"], "units": ["슈퍼마켓", "기타음식료품위주종합소매업", "과실 및 채소 소매업", "수산물 소매업", "육류 소매업"]}; 도민_대형종합 = {"groups": ["제주도민"], "units": ["기타 대형 종합 소매업"]}; 도민_편의점 = {"groups": ["제주도민"], "units": ["체인화 편의점"]}; 도민_화장품건강 = {"groups": ["제주도민"], "units": ["화장품 및 방향제 소매업", "건강보조식품 소매업"]}; 도민_잡화 = {"groups": ["제주도민"], "units": ["그외 기타 종합 소매업"]}
- 대상: 도민_주점 / 대조: 도민_식료품
- 사전 12 · 사후 6 · 계절 차분 없음(격차 그대로)
- 공간 위약: 도민_화장품건강 vs 도민_식료품, 도민_잡화 vs 도민_식료품
- 대체 대조(민감도): 대형종합만, 편의점만
- 시점 위약 제외 기간: 2020-02-01~2022-04-30(코로나19 방역 기간: 같은 종류의 조치(영업시간·모임 제한)가 계속 바뀌어 '정책 없는' 가짜 시행일이 될 수 없음)

## 3. 데이터 점검 결과(Data Scout)
- 측정 단절 진단: 단절 없음
- 커버리지: [집단 결측] 2023-05 ~ 2023-06 2개월 동안 기타외국, 동남아, 일본, 중국의 행이 없음 (같은 기간 내국인, 법인, 제주도민은 있음) (결측·부분 집계일은 분석에서 자동 제외)

## 4. 설계 선택과 이유
- 사전 등록 문서 사용: docs/prereg/case_distancing_2022.md (잠금 해시 확인)

## 5. 판정
- 판정 규칙 v2(`jverdict.causal.verdict`)를 그대로 적용한다. 결과를 본 뒤 설계를 바꾸면 변경 기록에 남기고 원안 판정을 함께 보고한다.
