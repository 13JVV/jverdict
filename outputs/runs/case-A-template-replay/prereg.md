# 사전 등록: 청소년 버스 무료(어린이 무료 확대)

- 이 문서는 효과 값을 보기 전에 만들어졌다. Design 단계에 전달된 자료는 데이터 계열 목록, 대조 후보, 커버리지 점검, 측정 단절 진단의 판정 이름·상한뿐이다(효과 크기가 담긴 Scout 메모는 넘기지 않음). 대조 선택 툴은 정책 전 기간만 본다.

## 1. 질문
- 청소년 버스 무료화(2025-08-01)로 청소년의 버스 이용이 늘었는가?
- 정책 시행일: 2025-08-01
- 처치 대상: 청소년(만 13~18세), 어린이 무료 확대 동시 시행
- 결과지표: 이용자 유형별 일 단위 버스 이용 인원
- 기대 방향: increase · 기준 효과: 10%

## 2. 데이터와 설계
- 데이터셋: 이용자 유형별 버스정류소 이용 인원 현황 (`bus_station`)
- 방법: 단절 시계열(대상/대조 격차, 계절 차분)
- 계열 정의: 청소년 = {"groups": ["청소년"], "units": null}; 어린이 = {"groups": ["어린이"], "units": null}; 일반 = {"groups": ["일반"], "units": null}; 경로 = {"groups": ["경로"], "units": null}; 장애 일반 = {"groups": ["장애 일반"], "units": null}
- 대상: 청소년 / 대조: 일반
- 사전 기본 · 사후 기본 · 계절 차분 3년
- 공간 위약: 경로 vs 일반, 장애 일반 vs 일반
- 대체 대조(민감도): 기본 사양
- 대조할 공식 통계: 어린이·청소년 무료 이용 누적 483만 건(도 발표, 2025-08~2026-02)

## 4. 설계 선택과 이유
- 대조 집단: 일반: 정책 대상이 아니고 규모가 가장 커 날씨·관광 등 공통 변화를 가장 잘 반영
- 공간 위약: 경로·장애 일반: 정책 대상이 아닌 다른 할인 유형. 같은 때 변하면 대조 쪽 사건을 의심
- 계절 차분 3년: 시행일(8월)이 방학과 겹쳐 같은 요일·같은 시기 과거 값과 비교
- 공식 통계 대조: 도 발표 483만 건: 공개 데이터 집계와 공식 실적의 규모 확인
