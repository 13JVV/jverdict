# 판정서: 청소년 버스 무료(어린이 무료 확대)

## 🟣 판정 보류

**청소년 버스 무료화(2025-08-01) 이후 이용이 늘었는지는 판정을 보류합니다. 집계 방식이 바뀌었을 가능성이 커서 정책 효과와 구분할 수 없습니다.**

2025-08-01부터 '청소년' 유형 이용 인원이 -76.5%(판정 구간 -81.9% ~ -70.4%) 바뀌었으나, 이는 이용이 늘었다는 근거가 아니라 오히려 감소로 나타난 값입니다. 데이터 품질 검증(C0)에서 측정 단절 의심(강)이 나왔고, 근거 3개가 정책 효과보다 집계 방식 변경을 가리킵니다. 무료 카드(교통복지카드)로 탄 기록이 '청소년'이 아닌 다른 유형으로 잡혔다면 실제 이용은 줄지 않고 기록만 줄었을 수 있습니다. 따라서 이 숫자를 정책 효과로 읽지 않고, 유형 분류 기준과 무료 카드 승차 기록을 확인한 뒤 다시 판단해야 합니다.

## 정책 카드

- 질문: 청소년 버스 무료화(2025-08-01)로 청소년의 버스 이용이 늘었는가?
- 시행일: 2025-08-01 · 대상: 청소년(만 13~18세), 어린이 무료 확대 동시 시행
- 결과지표: 이용자 유형별 일 단위 버스 이용 인원
- 데이터: 이용자 유형별 버스정류소 이용 인원 현황

## 근거

- C0 데이터 품질: 실패 — 측정 단절 의심(강). 2025-08-01부터 '청소년'이 -76% 바뀌었고, 근거 3개가 집계 방식 변경을 가리킴
- '측정 방식이 바뀌어 숫자만 달라졌다'는 반론은 성립(규칙 검증: 성립). 무료 카드 이용이 다른 유형으로 기록됐을 가능성 있음
- 참고용 추정 변화는 사후 82일 평균 -76.5%(판정 구간 -81.9% ~ -70.4%, p=0.006)이며 측정 문제와 구분할 수 없음
- 사전추세(p=0.17, 연장으로 설명되는 몫 2%), 시점 위약검정(177개 중 순위 p=0.006), 공간 위약검정(실제 -76.5% vs 가짜 처치 경로 -3.9%, 장애 -4.8%), 민감도(4개 중 4개 같은 방향·유의)는 통과
- 여름방학·전환기 제외(2025-07-20~2025-08-31 제외 시 -79.8%), 사후 60일만 볼 때 -74.1%로 반론은 기각됨
- C4 이중 계산은 pandas와 SQL 값이 -1.446824006으로 일치
