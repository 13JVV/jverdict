# 사전 등록: (시연) 청소년 야간 버스 증편 — 합성데이터 2

- 이 문서는 효과 값을 보기 전에 만들어졌다. Design 단계에 전달된 자료는 데이터 계열 목록, 대조 후보, 커버리지 점검, 측정 단절 진단의 판정 이름·상한뿐이다(효과 크기가 담긴 Scout 메모는 넘기지 않음). 대조 선택 툴은 정책 전 기간만 본다.

## 1. 질문
- 2024-09-02 청소년 야간 버스 증편으로 청소년 버스 이용이 늘었는가?
- 정책 시행일: 2024-09-02
- 처치 대상: 청소년
- 결과지표: 이용자 유형별 일 단위 버스 이용 인원
- 기대 방향: increase · 기준 효과: 10%

## 2. 데이터와 설계
- 데이터셋: 합성 버스 데이터 2 (같은 시기 행사가 섞인 시연용) (`synthetic_bus_event`)
- 방법: 단절 시계열(대상/대조 격차, 계절 차분)
- 계열 정의: 청소년 = {"groups": ["청소년"], "units": null}; 일반 = {"groups": ["일반"], "units": null}; 경로 = {"groups": ["경로"], "units": null}
- 대상: 청소년 / 대조: 일반
- 사전 기본 · 사후 기본 · 계절 차분 2년
- 공간 위약: 경로 vs 일반
- 대체 대조(민감도): 경로를 대조로 사용
- 시점 위약 제외 기간: 2024-09-16~2024-11-24(청소년 문화축제 연계 무료 셔틀·공연(가상 행사). 청소년 이동에 영향을 주므로 시점 위약의 가짜 시행일 창이 겹치면 안 됨); 2023-07-20~2023-08-20(여름방학. 청소년 이동 변화가 큼); 2024-07-20~2024-08-20(여름방학. 청소년 이동 변화가 큼); 2023-12-28~2024-02-25(겨울방학. 청소년 이동 변화가 큼); 2024-12-28~2025-02-25(겨울방학. 청소년 이동 변화가 큼)

## 3. 데이터 점검 결과(Data Scout)
- 측정 단절 진단: 측정 단절 증거 없음
- 커버리지: [부분 집계] 짧은 부분 집계 6건(6일): 합계가 평소의 7~15%. 해당 일은 분석에서 빼거나 가중치를 낮춰야 함 (결측·부분 집계일은 분석에서 자동 제외)

## 4. 설계 선택과 이유
- 대조 집단은 일반으로 정함: 정책 전 728일 동안 청소년과 가장 비슷하게 움직였음(상관 0.7353, 격차 변동 0.1443). 경로는 상관 0.692, 격차 변동 0.158로 약간 낮았음. 두 집단 모두 격차 추세는 연 -0.017~-0.018로 비슷해 큰 차이가 없음.
- 경로를 공간 위약 집단으로 쓰고 대체 대조로도 둠: 경로는 야간 증편 대상이 아니므로 시행 뒤 일반과의 격차가 변하면 설계 문제를 의심할 근거가 됨. 같은 집단을 대체 대조로 두어 결과가 대조 선택에 좌우되는지 확인함.
- 분석 방법은 its를 쓰고 사전 기간과 사후 기간은 기본값(null), 계절 차분은 과거 2년으로 함: 집계 시계열이고 기간을 바꿔야 할 특별한 이유가 없음. 방학과 명절의 계절 패턴을 걷어내려는 목적임.
- 2024-09-16부터 2024-11-24까지를 중요한 교란 사건으로 기록함: 시행일 2주 뒤에 청소년 문화축제 연계 무료 셔틀·공연이 시작됨. 청소년에게만 영향을 주는 사건이라 증편 효과와 분리하기 어려움. 사후 기간 대부분이 겹쳐 원인을 단정할 수 없으므로 결과를 해석할 때 이 한계를 함께 적어야 함. 이 사건은 가상 행사임.
- 방학 기간도 시점 위약의 제외 구간에 넣음: 방학은 청소년 이동을 크게 바꾸는 사건이라 가짜 시행일 창이 겹치면 안 됨.
- 부분 집계 6일은 exclude에 넣지 않음: 품질 점검에서 자동으로 제외됨.
- 의미 있는 최소 효과는 10%로 하고 증가를 기대함: 정책 카드의 기본값과 기대 방향을 따름. 야간 시간대만 따로 볼 수 없어 청소년 전체 이용 인원으로 대체했으므로 효과가 희석될 수 있음(확인 필요).

## 5. 판정
- 판정 규칙 v2(`jverdict.causal.verdict`)를 그대로 적용한다. 결과를 본 뒤 설계를 바꾸면 변경 기록에 남기고 원안 판정을 함께 보고한다.
